# FVG Trading Bot (Python)

## Overview
This project demonstrates a simple Fair Value Gap (FVG) trading strategy using historical price data.

## Features
- Detects bullish and bearish FVG zones
- Outputs basic trade signals
- Clean and modular structure

## Tech Stack
- Python
- Pandas

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python main.py
